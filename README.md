## Netlify

Netlify non ha una traduzione ufficiale in italiano, perché è un nome di marca composto da:

Net = rete, web, Internet
-lify = suffisso inglese che significa "rendere", "trasformare in"

Quindi, come traduzione "con senso", potrebbe significare:

"Mettere in rete"
"Rendere disponibile sul web"
"Pubblicare online"
"Trasformare in un sito web accessibile"

Per chi sviluppa siti, il significato più vicino è:

"Pubblicare e distribuire un sito su Internet in modo semplice e automatico."

È un po' come se Netlify significasse: "webbizzare" o "portare sul web".
